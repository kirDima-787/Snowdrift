# Предупреждения Windows SmartScreen и Defender

## Почему Windows может показывать предупреждение

При запуске Snowdrift фильтр Windows SmartScreen может показать окно с сообщением:
> «Система Windows защитила ваш компьютер» (Windows protected your PC)

а встроенный антивирус Microsoft Defender — предупреждение системы безопасности.

Это стандартное поведение Windows при запуске недавно опубликованных бесплатных программ с открытым исходным кодом. Причины:

- файл загружен из сети интернет;
- программа недавно выпущена и ещё не успела накопить достаточную репутацию в облачной базе Microsoft;
- у исполняемого файла пока нет коммерческой цифровой подписи (Code Signing Certificate).

Snowdrift — полностью открытый проект (Open Source). Исходный код приложения доступен для проверки в этом репозитории и не содержит вредоносного кода или скрытых действий.

## Как запустить приложение

### 1. Если появилось окно Windows SmartScreen

1. В синем окне предупреждения нажмите ссылку **«Подробнее»** (More info).
2. В правом нижнем углу нажмите появившуюся кнопку **«Выполнить в любом случае»** (Run anyway).

После этого приложение запустится в штатном режиме, а Windows запомнит ваш выбор для последующих запусков.

### 2. Проверка подлинности и целостности (SHA-256)

Если вы хотите убедиться, что скачанный установочный файл полностью соответствует оригинальной сборке разработчика и не был повреждён при загрузке:

1. Откройте PowerShell в папке со скачанным файлом и выполните команду:

   ```powershell
   Get-FileHash .\Snowdrift-Setup.exe -Algorithm SHA256
   ```

2. Сравните полученный хэш со значением в файле `SHA256SUMS.txt`, прикреплённом к соответствующему релизу на GitHub:
   [Страница официальных релизов Snowdrift](https://github.com/kirDima-787/Snowdrift/releases).

### 3. Если файл был заблокирован Microsoft Defender

В редких случаях эвристический анализ Defender может по ошибке заблокировать новый файл. Чтобы восстановить его:

1. Откройте меню **Пуск** и перейдите в **Безопасность Windows** (Windows Security).
2. Выберите **Защита от вирусов и угроз → Журнал защиты** (Protection history).
3. Найдите недавнюю запись о блокировке `Snowdrift.exe` или `Snowdrift-Setup.exe`.
4. Нажмите **Действия → Восстановить** (Actions → Restore) или **Разрешить на устройстве**.

### 4. Smart App Control (Windows 11)

В Windows 11 существует функция **Smart App Control (SAC)**. Если она работает в режиме «Принудительно» (Enforced), система может блокировать запуск программ без коммерческой цифровой подписи.

Проверить текущий статус SAC можно по пути:
**Параметры Windows → Конфиденциальность и защита → Безопасность Windows → Управление приложениями и браузером → Smart App Control**.
