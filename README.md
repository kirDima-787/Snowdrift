# Snowdrift ❄️

Красивый и легковесный падающий снег на вашем рабочем столе Windows.

Снежинки мягко кружатся на экране, оседают на верхних гранях открытых окон и тают, срываются хлопьями при перетаскивании окон и разлетаются от движения курсора мыши.

---

## Особенности

- ❄️ **Физика опадания и сугробов**: Снег накапливается на панели задач и на верхних гранях любых открытых окон.
- 🖱️ **Интерактивность**: Проведите курсором мыши через сугроб — снег разлетится в стороны. Переместите или встряхните окно — скопившийся снег соскользнёт вниз.
- 🎛️ **Управление в системном трее**:
  - **Snowfall**: интенсивность снегопада (*Off*, *Light*, *Steady*, *Heavy*, *Variable*).
  - **Accumulate**: накапливать сугробы на поверхностях.
  - **Melt Snow**: медленное плавное таяние сугробов, чтобы они не загромождали экран.
  - **Snow on Windows**: снег на гранях окон.
  - **Behind Windows**: снег только позади окон (на обоях).
  - **Clear Snow**: мгновенно смахнуть весь снег с экрана.
  - **Open at Login**: автозапуск вместе с Windows.
- 🛡️ **100% приватность и автономность**:
  - Полностью отключены любые сетевые вызовы и проверки обновлений.
  - Приложение не запрашивает права администратора.
  - Аппаратное ускорение через Direct3D 11 / DirectComposition — потребляет всего ~6% одного ядра процессора и ~65 МБ памяти.

---

## Где находятся файлы

Собранные бинарники расположены в папке `dist/`:
- **`dist/Snowdrift.exe`** (~710 КБ) — портативная версия. Можно запускать напрямую без установки!
- **`dist/Snowdrift-Setup.exe`** (~1.1 МБ) — установщик в стиле карточки с ярлыком в меню «Пуск».

---

## Сборка из исходников

```sh
# Портативная сборка:
cargo build --release --bin Snowdrift

# Сборка установщика:
$env:SNOWDRIFT_APP = "target/release/Snowdrift.exe"
cargo build --release --features setup --bin Snowdrift-Setup
```
